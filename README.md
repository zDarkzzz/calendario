# Calendário com Etiquetas

Calendário para celular: pinte cada dia com uma cor (cada cor tem nome e valor em R$),
escreva uma etiqueta no dia e envie o resumo de cada quinzena em PDF ou Excel, com os dados do Pix.

- Funciona como aplicativo: abra o endereço no celular e escolha "Instalar app" / "Adicionar à tela de início".
- Funciona sem internet depois de aberto uma vez.
- Os dados de cada pessoa ficam somente no próprio celular dela.
